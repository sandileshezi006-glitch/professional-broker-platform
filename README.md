# NorthStar Brokerage Website

A premium broker-style landing page built in plain HTML, CSS, and JavaScript.

## Features
- Professional luxury real-estate / investment branding
- Responsive layout for desktop and mobile
- Premium hero section with background imagery
- Services, market, insights, testimonials, and CTA sections
- Smooth navigation and modern visual design

## Files
- `index.html`
- `styles.css`
- `script.js`

## Deployment
This is a static website and can be deployed on any static hosting platform, including:
- GitHub Pages
- Netlify
- Vercel
- Cloudflare Pages

### GitHub Pages quick setup
1. Push this repo to GitHub
2. Open the repository in GitHub
3. Go to Settings > Pages
4. Select the branch `main`
5. Set the folder to `/root`
6. Save and wait for the site to publish

## Local preview
Open `index.html` in a browser, or run a local web server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
